Полноценный кооперативный многопользовательский мод (2 игрока) для градостроительной стратегии на выживание **Ratopia** (Cassel Games).

Мод позволяет играть вдвоем на одной карте в реальном времени: с отдельными Королевами, полной синхронизацией колонии, жителями, стройкой, раскопками, животными, экономикой и деревом исследований.

---

## 🌟 Основные возможности

- **Две независимые Королевы:**
  - Хост управляет Королевой 1 (ID 777), клиент управляет Королевой 2 (ID 778).
  - У каждого игрока собственный интерфейс, прокачка навыков, инвентарь, оружие, боёвка и анимации Spine 2D.
  - Реализована механика возрождения: если один из игроков пал, второй может подойти и поднять союзника.
- **Модульная архитектура с библиотекой `RatopiaUnitBrain`:**
  - Полное отключение локального просчёта ИИ у клиента (`RemotePuppet` режим). Вся симуляция мира выполняется на хосте, устраняя десинхронизацию.
  - Плавная покадровая интерполяция (60–144 FPS) без рывков и телепортаций: клиент ведет марионеток по точкам маршрута хоста с предсказанием скорости.
  - Синхронизация жителей, стражей, боевых дронов, роботов-помощников и диких животных.
- **Синхронизация мира и строительства:**
  - Раскопки и добыча ресурсов в реальном времени.
  - Синхронизация рамок выделения игрока (`MiningBox`: копка, сбор, снос).
  - Совместная разметка чертежей зданий и завершение строительства.
- **Экономика и исследования:**
  - Синхронизация казны, костяных медалей, очков исследований и уровня процветания.
  - Разблокировка технологий в древе исследований сразу для обоих игроков.
- **Сетевой стек и удобное лобби:**
  - Высокопроизводительный UDP-транспорт на базе **LiteNetLib** (порт 7777).
  - Автоматический поиск хоста в локальной сети (LAN Broadcast Discovery).
  - Внутриигровое меню (клавиша **F9**), чат (клавиша **Enter**), плашка статуса подключения.
  - Передача живого сейва хоста клиенту при подключении (стриминг архива чанками по 16 КБ с мгновенной распаковкой и бесшовным входом).

## 🏗 Архитектура проекта

Проект разделен на два взаимосвязанных решения:

```
ratopia-coop/
├── unitbrain/                # Библиотека прямого управления ИИ (RatopiaUnitBrain.dll)
│   ├── Data/                 # Сетевые ID юнитов, снимки состояний, дескрипторы задач
│   ├── Registry/             # Реестр O(1) всех GameUnit и AnimalBody в мире
│   ├── Sensor/               # Сенсоры хоста (перехват маршрутов A*, задач, урона, рюкзака)
│   └── Puppeteer/            # Движок марионеток клиента (подавление локального ИИ, сглаживание)
│
└── coop/                     # Основной мод кооператива (RatopiaCoop.dll)
    ├── Network/              # LiteNetLib менеджер, сокеты, бинарные пакеты (PacketType)
    ├── Sync/                 # Подсистемы синхронизации (Королевы, Мир, Жители, Сейвы, Экономика, Чат)
    ├── Patches/              # Harmony-патчи (T_Queen, TileMgr, MiningBox, Research, Steam)
    └── UI/                   # Внутриигровой IMGUI-интерфейс (F9 лобби, чат, баннер)
```

---

## 🎮 Управление в кооперативе

| Клавиша | Действие |
|---|---|
| **F9** | Открыть / закрыть меню мультиплеера (хост, подключение, поиск LAN) |
| **Enter** | Открыть чат / отправить сообщение (блокирует ввод игры во время набора) |
| **E / Взаимодействие** | Возродить павшего напарника при приближении |

## 📥 Установка и запуск

### Требования
- Установленная игра *Ratopia* (версия для ПК, Steam / DRM-free).
- Установленный **BepInEx 5.4.23.2 (x64)** в папке с игрой.

### Пошаговая инструкция
1. Скачайте последний релиз из вкладки [Releases](../../releases).
2. Распакуйте архив в папку игры:
   ```
   Ratopia/
   └── BepInEx/
       └── plugins/
           ├── RatopiaUnitBrain/
           │   └── RatopiaUnitBrain.dll
           └── RatopiaCoop/
               ├── RatopiaCoop.dll
               └── LiteNetLib.dll
   ```
3. Запустите игру. В верхнем левом углу появится статус мода, а по нажатию **F9** откроется меню мультиплеера.
4. **Хост:** Создайте или загрузите мир, нажмите **F9** $\rightarrow$ **«Start Server (Host)»**.
5. **Клиент:** В главном меню нажмите **F9** $\rightarrow$ найдите сервер через **«Find LAN Servers»** или введите IP хоста и нажмите **«Connect»**. Мир автоматически загрузится с хоста!

## 🛠 Сборка из исходного кода

Для компиляции требуется [.NET SDK 6.0+](https://dotnet.microsoft.com/download):

```powershell
# 1. Клонировать репозиторий
git clone https://github.com/kortonit-coop-dev/ratopia-coop.git
cd ratopia-coop

# 2. Собрать библиотеку UnitBrain
dotnet build unitbrain/RatopiaUnitBrain.csproj

# 3. Собрать мод RatopiaCoop
dotnet build coop/RatopiaCoop.csproj
```

*Зависимости игры автоматически подтягиваются из локальной папки `../Ratopia/Ratopia_Data/Managed/`.*
